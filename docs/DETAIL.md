# 会话搜索（Session Search）

命令面板式的当前会话内容搜索。本页与 README 同源；安装后在插件管理器中可见。

## 快速上手

1. `Ctrl+F` 或点击会话标题栏右侧的放大镜按钮，打开搜索面板；
2. 输入关键字，面板即时列出命中行（角色徽标 + 时间 + 高亮片段）；
3. ↑↓ 选择、Enter 跳转，或直接点击结果——聊天流滚动定位到对应消息，行描边 + 关键词亮黄闪烁两下；
4. Esc 或点击遮罩关闭。

## 过滤与深度搜索

- 角色过滤 chips：**对话**（默认：用户 + 助手发言）/ **用户** / **助手** / **其它**（工具结果、命令、错误等机器过程行）；
- **深度搜索（加载更早内容）**：底部按钮，后台逐页拉取更早历史并重建索引，可随时取消；连续两页无新增即到顶。

## 范围与限制

- 搜索范围为当前会话**已加载**的消息窗口，更早历史通过深度搜索或手动向上滚动加载；
- 折叠的思考过程成员不参与搜索（展开后重新打开面板即可）；
- 时间标签来自宿主渲染的时钟元素（用户行与回合收尾行），其余行继承所属回合的完成时间；
- 实现细节、诊断日志与完整限制清单见仓库 README。
