# DSH Session Search

[English](README.en.md) | 中文

DeepSeek Harness 桌面客户端的会话内容搜索插件：命令面板式的当前会话搜索。`Ctrl+F` 或会话标题栏放大镜按钮唤起，输入关键字即时命中、高亮显示，按角色过滤，Enter 跳转到对应消息并闪烁关键词。以 dsh bundle 形式安装，不修改 DSH 源码。

## 使用

- **`Ctrl+F`**（或点击标题栏放大镜按钮）：打开搜索面板；
- 输入关键字：即时列出当前会话已加载内容中的命中行（角色徽标 + 时间 + 命中片段高亮）；
- **↑↓** 选择、**Enter** 跳转（或直接点击结果）：聊天流滚动定位到对应消息，目标行描边 + 关键词亮黄闪烁两下；
- **Esc** / 点击遮罩：关闭面板；
- 角色过滤 chips：**对话**（默认，用户 + 助手发言）/ **用户** / **助手** / **其它**（工具结果、命令、错误等机器过程行，显式点它才参与搜索）；
- **深度搜索（加载更早内容）**：面板底部按钮。后台逐页拉取更早历史并重建索引（走宿主 `loadOlder` 通道，不滚动聊天流），连续两页无新增即「已加载到顶」；加载期间可继续输入、可取消，上限 200 页。

## 安装

```sh
dsh plugin --profile web add dsh-session-search
```

或在 dshmarket 插件市场搜索 session search。

要求：DSH 桌面版 ≥ 0.2.1（Windows / macOS 均可，纯前端实现无平台依赖）。

从源码安装：

```sh
git clone https://github.com/shegan1/dsh-session-search
dsh plugin --profile web add ./dsh-session-search
```

## 实现说明

插件为纯客户端 bundle（宿主半 `index.js` 为空实现）：

- **搜索索引**：打开面板时一次性扫描聊天流 DOM——宿主为每行渲染的 `data-chat-anchor-key` / `data-chat-flow-kind` / `data-chat-turn` 是跨版本稳定的公开契约，索引内容（`textContent`，含折叠体）与跳转定位共享同一坐标系统，不存在搜得到跳不到的错位；
- **时间显示**：宿主只在用户行与回合收尾行渲染时钟（CSS 类名含 `timeStart`/`timeEnd` 的 span，悬停才可见但常驻 DOM），插件按类名定位读取；其余行按回合号就近继承所属回合的完成时间，结果按解析后的时间戳排序（`HH:MM` 按今天、`M月D日 HH:MM` 按今年、`YYYY年M月D日 HH:MM` 逐字）；
- **跳转**：手动计算目标行在滚动容器内的偏移直接写 `scrollTop`（确定性单帧滚动，避开宿主底部跟随/滚动锚定的回拉），下一帧补滚一次双保险；折叠组内的隐藏行在索引时过滤，精确行不可见时就近落点；
- **关键词闪烁**：CSS Custom Highlight API 在目标行内高亮命中词，闪烁两下后自动注销，不残留宿主 DOM；
- **深度搜索**：通过会话对象的标准 `loadOlder()` 行为逐页回填历史（视口不动），每页重建索引；`loadOlder` 不可用时退回程序化滚顶翻页。

诊断信息输出到浏览器 Console（`[session-search]` 前缀：索引行数、时钟探测、每次跳转的查找分类与滚动前后位置）。

## 已知限制

- 搜索范围为会话的**已加载**消息窗口；默认只拉最近一页，更早历史需深度搜索或先在聊天流中向上滚动加载；
- 折叠的思考过程组成员不参与搜索（宿主 `display:none`，跳过去也不可见）；展开后重新打开面板即可搜到；
- 时间标签依赖宿主渲染的时钟元素：宿主未来若改版时钟类名，时间列会静默缺失（不影响搜索与跳转）；
- 每行文本参与匹配的上限 20k 字符，结果列表上限 100 条。
